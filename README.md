Deskripsi tentang aplikasi DUA HATI, permainan kartu obrolan interaktif untuk pasangan.

Fitur Utama:
1. Penjelasan Mode Offline (1 Layar) untuk bermain langsung bertatap muka.
2. Penjelasan Mode Online (2 HP) dengan sinkronisasi instan melalui Socket.IO, jawaban rahasia, indikator pengetikan, dan synchronized reveal.
3. Rincian ke-9 deck percakapan (Obrolan Harian, Deep Talk, This or That, Harapan & Impian, Kenali Diriku, Chaos Mode, Cinta & Kita, Seberapa Paham?, dan Katakan Sesuatu).
4. Dukungan 2 bahasa (ID/EN) dan desain tipografi editorial yang bersih.
5. Tech Stack: React 19, TypeScript, Vite, Tailwind CSS v4, Motion, Express.js, dan Socket.IO.
6. Panduan Menjalankan Secara Lokal (Quickstart): Langkah-langkah instalasi, menjalankan server development, hingga cara mengetes mode 2 HP pada jaringan Wi-Fi lokal.
7. Struktur Direktori Proyek: Pemetaan modul dan komponen utama aplikasi.

8. Kunjungi https://duahati.ai.studio/ dan selamat mengenal pasangan lebih dekat
